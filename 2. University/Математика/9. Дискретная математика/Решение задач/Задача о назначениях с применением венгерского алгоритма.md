## Алгоритм Венгерский 

1. **Редукция строк** - вычесть минимум каждой строки из всех элементов строки.
2. **Редукция столбцов** - вычесть минимум каждого столбца.
3. **Покрытие нулей** - найти минимальное число линий (строк/столбцов), покрывающих все нули.
4. Если число линий $= n$ оптимальное назначение найдено. Иначе — найти минимальный непокрытый элемент $\delta$, вычесть его из непокрытых, прибавить к дважды покрытым. Перейти к шагу 3.
5. Восстановить назначение по нулям.

### Редукция столбцов

$$\begin{pmatrix} 3&7&3&5&4&\mathbf{0}&7&1\ 6&1&\mathbf{0}&4&\mathbf{0}&3&6&7\ \mathbf{0}&\mathbf{0}&8&6&2&2&3&4\ \mathbf{0}&7&4&4&4&\mathbf{0}&4&4\ 2&7&7&2&1&9&\mathbf{0}&7\ 4&6&4&6&1&\mathbf{0}&7&6\ 8&4&1&\mathbf{0}&2&\mathbf{0}&4&7\ 1&5&\mathbf{0}&3&4&3&1&\mathbf{0} \end{pmatrix}$$

### Покрытие нулей

Максимальное паросочетание по нулям: $W_1{-}J_6,\ W_2{-}J_3,\ W_3{-}J_2,\ W_4{-}J_1,\ W_5{-}J_7,\ W_7{-}J_4,\ W_8{-}J_8$ — размер 7. $W_6$ не покрыта.

Чередующийся путь из $W_6$: $W_6 \to J_6 \to W_1$ (тупик — у $W_1$ нет других нулей).

По теореме Кёнига минимальное покрытие (7 линий):

- **Строки:** $W_2, W_3, W_4, W_5, W_7, W_8$
- **Столбец:** $J_6$

$7 < 8$, нужна ещё одна итерация.

---

### Обновление матрицы

Непокрытые клетки (строки $W_1, W_6$; столбцы $J_1$–$J_5$, $J_7$, $J_8$):

$$\delta = \min = 1 \quad \text{(клетки } W_1{-}J_8 \text{ и } W_6{-}J_5\text{)}$$

- Вычесть 1 из непокрытых клеток.
- Прибавить 1 к дважды покрытым (пересечение строк $W_2,W_3,W_4,W_5,W_7,W_8$ и столбца $J_6$).
