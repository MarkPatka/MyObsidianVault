## Алгоритм Беллмана-Мура

1. Инициализировать $d[X_1]=0$, $d[v]=\infty$ для остальных вершин.
2. Выполнить $n-1 = 7$ итераций: на каждой пройти по **всем** дугам $(u \to v)$ и выполнить релаксацию: $$d[v] = \min\bigl(d[v],\ d[u] + w(u,v)\bigr)$$
3. Проверить на отрицательные циклы: если на $n$-й итерации хоть одно значение $d$ изменилось — цикл есть.
4. Восстановить путь по массиву $\text{prev}$.

## Решение

$$d = [0,\ \infty,\ \infty,\ \infty,\ \infty,\ \infty,\ \infty,\ \infty]$$

### **Итерация 1** 

| Дуга                 | Расчёт                          | Обновление                           |
| -------------------- | ------------------------------- | ------------------------------------ |
| $X_1 \to X_3$        | $0 + 10 = 10 < \infty$          | $d[X_3] = 10,\ \text{prev}[X_3]=X_1$ |
| $X_1 \to X_5$        | $0 + (-2) = -2 < \infty$        | $d[X_5] = -2,\ \text{prev}[X_5]=X_1$ |
| $X_1 \to X_6$        | $0 + 9 = 9 < \infty$            | $d[X_6] = 9,\ \text{prev}[X_6]=X_1$  |
| $X_1 \to X_8$        | $0 + 5 = 5 < \infty$            | $d[X_8] = 5,\ \text{prev}[X_8]=X_1$  |
| $X_3 \to X_5$        | $10 + (-9) = 1 > -2$            | без изменений                        |
| $X_3 \to X_7$        | $10 + 14 = 24 < \infty$         | $d[X_7] = 24,\ \text{prev}[X_7]=X_3$ |
| $X_3 \to X_8$        | $10 + (-4) = 6 > 5$             | без изменений                        |
| $X_5 \to X_7$        | $-2 + 13 = 11 < 24$             | $d[X_7] = 11,\ \text{prev}[X_7]=X_5$ |
| $X_5 \to X_8$        | $-2 + 7 = 5 = 5$                | без изменений                        |
| $X_6 \to X_8$        | $9 + (-3) = 6 > 5$              | без изменений                        |
| $X_8 \to X_7$        | $5 + 11 = 16 > 11$              | без изменений                        |
| $X_2,X_4 \to \ldots$ | $d[X_2]=\infty,\ d[X_4]=\infty$ | недостижимы                          |

$$d = [0,\ \infty,\ 10,\ \infty,\ -2,\ 9,\ 11,\ 5]$$

## Восстановление пути

$d[X_8] = 5$ достигается двумя равноценными путями:

$$X_1 \xrightarrow{5} X_8$$

$$X_1 \xrightarrow{-2} X_5 \xrightarrow{7} X_8$$

$$\boxed{\omega_{\min}(X_1 \to X_8) = 5}$$
