## Задача 2
Докажите алгебраически, что данная формула является тавтологией:

$$C(a, b, c) = ((a \to b) \oplus (b \to c)) \to (abc \mid (a \to b))$$
### Решение
**Шаг 1. Обозначения и замены.**
Пусть 
$\alpha = a \to b = \neg a \lor b$ 
$\ \beta = b \to c = \neg b \lor c$ 
Формула: $C = (α \oplus β) \to (a \lor b \lor c \mid α)$.

**По определению штриха Шеффера:**
$$abc \mid \alpha = \neg(abc \cdot \alpha)$$
Раскроем $(a \lor b \lor c) \cdot a$:
$$abc \cdot (\neg a \lor b) = abc\neg a \lor abcb = a\neg a \cdot bc \lor abc = 0 \lor abc = abc$$
Здесь: $a\cdot \neg a = 0, \ b \cdot b = b$.

Итого: $a \lor b \lor c \mid α = \neg(abc)$.

**Формула приняла вид:**
$$C = (\alpha \oplus \beta) \to \neg(abc)$$
Для доказательства тавтологии $(X \to Y \equiv 1)$ достаточно показать, что $X \cdot \neg Y = 0$, т.е.:
$$(\alpha \oplus \beta) \cdot abc = 0$$
Раскроем XOR:
$$(\alpha \oplus \beta) \cdot abc = (\alpha\neg\beta \lor \neg\alpha\beta) \cdot abc = \alpha\neg\beta \cdot abc \;\lor\; \neg\alpha\beta \cdot abc$$
Вычислим отрицания:
- $¬β = \neg(\neg b \lor c) = b \neg c$
- $\neg α = \neg (\neg a \lor b) = a \neg b$

**Первое слагаемое:**
$$\alpha \cdot \neg\beta \cdot abc = (\neg a \lor b) \cdot b\neg c \cdot abc = (\neg a \lor b) \cdot abc\neg c = (\neg a \lor b) \cdot 0 = 0$$
поскольку $c \cdot  \neg c = 0$.

**Второе слагаемое:**
$$\neg\alpha \cdot \beta \cdot abc = a\neg b \cdot (\neg b \lor c) \cdot abc = a\neg b \cdot abc \cdot (\neg b \lor c) = \ldots$$
но уже a$\neg b \cdot abc = a \cdot b \neg b \cdot c = 0$, поскольку $b \cdot \neg b = 0$.

**Итог:**
$$(\alpha \oplus \beta) \cdot abc = 0 \lor 0 = 0$$
Следовательно:
$$C = (\alpha \oplus \beta) \to \neg(abc) = \neg((\alpha \oplus \beta) \cdot abc) = \neg 0 = 1$$
$\boxed{Формула \ является \ тавтологией. \square }$ 

## Задача 3
Приведите алгебраически данную формулу к СДНФ:

$$P(a, b, c) = 1 \oplus \bigl((a \lor \bar{b} \lor a\bar{c}) \mid (a \lor b \lor c)\bigr)$$
### Решение
Применяем $1 \oplus X = \neg X$:
$$P = \neg\!\left(\overline{(a \lor \bar{b} \lor a\bar{c})} \mid (a \lor b \lor c)\right)$$
**Раскрываем отрицание штриха Шеффера: $\neg(x \mid y) = x \cdot y$:
$$P = \overline{(a \lor \bar{b} \lor a\bar{c})} \cdot (a \lor b \lor c)$$
Упрощаем выражение под верхней чертой. По закону поглощения $a \lor a\bar{c} = a$:
$$a \lor \bar{b} \lor a\bar{c} = a \lor \bar{b}$$
Применяем закон де Моргана:
$$\overline{a \lor \bar{b}} = \bar{a} \cdot b$$
Подставляем и раскрываем:
$$P = \bar{a}\,b \cdot (a \lor b \lor c) = \bar{a}\,b\,a \lor \bar{a}\,b\,b \lor \bar{a}\,b\,c$$
- $\bar{a}\,b\,a = 0$ (поскольку $a \cdot \bar{a} = 0$)
- $\bar{a}\,b\,b = \bar{a}\,b$ (поскольку $b \cdot b = b$)
- $\bar{a}\,b\,c$ - оставляем
$$P = \bar{a}\,b \lor \bar{a}\,b\,c$$
По закону поглощения ($\bar{a}\,b$ поглощает $\bar{a}\,b\,c$):
$$P = \bar{a}\,b$$
Приводим к СДНФ. Конъюнкт $\bar{a}\,b$ не содержит переменной $c$ - домножаем на $(c \lor \bar{c})$:
$$P = \bar{a}\,b\,(c \lor \bar{c}) = \bar{a}\,b\,c \lor \bar{a}\,b\,\bar{c}$$
#### Ответ
$$\boxed{P(a,b,c) = \bar{a}\,b\,\bar{c} \lor \bar{a}\,b\,c}$$
## Задача 4
Приведите алгебраически данную формулу к СКНФ:
$$P(a, b, c) = \bigl(1 \oplus ((a \lor \bar{b} \lor a\bar{c}) \oplus a)\bigr) \lor b$$
### Решение
Упрощаем внутреннее выражение. По закону поглощения $a \lor a\bar{c} = a$:
$$a \lor \bar{b} \lor a\bar{c} = a \lor \bar{b}$$
Раскрываем $(a \lor \bar{b}) \oplus a$ по определению $x \oplus y = x\bar{y} \lor \bar{x}y$:
$$(a \lor \bar{b}) \oplus a = (a \lor \bar{b})\bar{a} \;\lor\; \overline{(a \lor \bar{b})} \cdot a$$
Первое слагаемое:
$$(a \lor \bar{b})\bar{a} = a\bar{a} \lor \bar{b}\bar{a} = 0 \lor \bar{a}\bar{b} = \bar{a}\bar{b}$$
Второе слагаемое (де Морган: $\overline{a \lor \bar{b}} = \bar{a} \cdot b$):
$$\bar{a}\,b \cdot a = a\bar{a} \cdot b = 0$$
Итого:
$$(a \lor \bar{b}) \oplus a = \bar{a}\bar{b}$$
Применяем $1 \oplus X = \neg X$:
$$1 \oplus \bar{a}\bar{b} = \overline{\bar{a}\bar{b}}$$
По де Моргану:
$$\overline{\bar{a}\bar{b}} = a \lor b$$
Подставляем в формулу:
$$P = (a \lor b) \lor b = a \lor b$$
Приводим к СКНФ. Дизъюнкт $(a \lor b)$ не содержит переменной $c$ - прибавляем $c\bar{c} = 0$:
$$a \lor b = (a \lor b \lor c\bar{c})$$
Раскрываем по дистрибутивности $\lor$ относительно $\land$:
$$a \lor b \lor c\bar{c} = (a \lor b \lor c)(a \lor b \lor \bar{c})$$
#### Ответ
$$\boxed{P(a,b,c) = (a \lor b \lor c)(a \lor b \lor \bar{c})}$$
## Задача 5
Приведите алгебраически заданную функцию к полиному Жегалкина

$$Z(a, b, c) = \bigl((ab \to (a \downarrow b)) \sim ((a \lor b) \to (a \mid b))\bigr)(a \oplus c)$$
### Решение

Вычисляем $a \downarrow b$:
$$a \downarrow b = 1 \oplus a \oplus b \oplus ab$$
Вычисляем $ab \to (a \downarrow b)$, используя $x \to y = 1 \oplus x(1 \oplus y)$:
$$1 \oplus ab\bigl(1 \oplus (1 \oplus a \oplus b \oplus ab)\bigr) = 1 \oplus ab(a \oplus b \oplus ab)$$
Раскрываем скобки (помня, что $a^2 = a$, $b^2 = b$):
$$ab(a \oplus b \oplus ab) = a^2b \oplus ab^2 \oplus a^2b^2 = ab \oplus ab \oplus ab = ab$$
Здесь $ab \oplus ab = 0$, остаётся $ab$. Итого:
$$ab \to (a \downarrow b) = 1 \oplus ab$$
Вычисляем $a \mid b$:
$$a \mid b = 1 \oplus ab$$
Вычисляем $a \lor b$:
$$a \lor b = a \oplus b \oplus ab$$
Вычисляем $(a \lor b) \to (a \mid b) = 1 \oplus x(1 \oplus y)$, где $x = a \oplus b \oplus ab$, $y = 1 \oplus ab$:
$$1 \oplus y = ab$$
$$x(1 \oplus y) = (a \oplus b \oplus ab) \cdot ab = a^2b \oplus ab^2 \oplus a^2b^2 = ab \oplus ab \oplus ab = ab$$
Итого:
$$(a \lor b) \to (a \mid b) = 1 \oplus ab$$ Обе части оказались одинаковы. Вычисляем эквивалентность $L \sim R = 1 \oplus L \oplus R$:
$$L = R = 1 \oplus ab$$
$$(1 \oplus ab) \sim (1 \oplus ab) = 1 \oplus (1 \oplus ab) \oplus (1 \oplus ab) = 1 \oplus 0 = 1$$
Парные слагаемые $(1 \oplus ab) \oplus (1 \oplus ab) = 0$ сократились.

Подставляем в исходную формулу:
$$Z = 1 \cdot (a \oplus c) = a \oplus c$$
#### Ответ
$$\boxed{Z(a,b,c) = a \oplus c}$$
## Задача 6
используя принцип двойственности, постройте формулу, реализующую функцию, двойственную к 𝜂, и убедитесь, что полученная формула эквивалентна формуле ℱ:

### Решение
Формула $\eta = ab \lor bc \lor cd$ содержит только $\land$ и $\lor$ - принцип двойственности применим напрямую.

Применяем принцип двойственности - заменяем $\lor \to \land$ и $\land \to \lor$:
$$\eta^* = (a \lor b)(b \lor c)(c \lor d)$$
Раскрываем скобки. Сначала первые две:
$$(a \lor b)(b \lor c) = ab \lor ac \lor b^2 \lor bc = ab \lor ac \lor b \lor bc$$
По закону поглощения: $b$ поглощает $ab$ и $bc$ (т.к. $ab \leq b$ и $bc \leq b$):
$$(a \lor b)(b \lor c) = b \lor ac$$
Умножаем результат на третью скобку:
$$(b \lor ac)(c \lor d) = bc \lor bd \lor ac^2 \lor acd = bc \lor bd \lor ac \lor acd$$
По закону поглощения: $ac$ поглощает $acd$:
$$\eta^* = ac \lor bc \lor bd$$
Сравниваем:
$$\eta^* = ac \lor bc \lor bd = \mathcal{F}$$
#### Ответ
Двойственная функция $\eta^* = (a \lor b)(b \lor c)(c \lor d) = ac \lor bc \lor bd$, что совпадает с $\mathcal{F}$. $\;\blacksquare$

## Задача 7
Найдите количество функций, зависящих от переменных 𝑥1, . . . , 𝑥𝑛, в заданном классе 𝑅

$$R = (T_0 \setminus T_1) \cap S$$
### Решение
**Определения.**
- $T_0$ - функции, сохраняющие 0: $f(0, \ldots, 0) = 0$
- $T_1$ - функции, сохраняющие 1: $f(1, \ldots, 1) = 1$
- $S$ - самодвойственные функции: $f(\neg x_1, \ldots, \neg x_n) = \neg f(x_1, \ldots, x_n)$

**Условие $T_0 \setminus T_1$.**
$f \in T_0 \setminus T_1$ означает:
$$f(0, \ldots, 0) = 0 \quad \text{и} \quad f(1, \ldots, 1) \neq 1, \;\text{т.е.}\; f(1, \ldots, 1) = 0$$
**Проверяем совместимость с $S$.**
Пусть $f \in S$. Подставим в определение самодвойственности набор $(0, \ldots, 0)$:
$$f(\neg 0, \ldots, \neg 0) = \neg f(0, \ldots, 0)$$
$$f(1, \ldots, 1) = \neg f(0, \ldots, 0)$$
Если при этом $f \in T_0$, т.е. $f(0, \ldots, 0) = 0$, то: $f(1, \ldots, 1) = \neg 0 = 1$
Значит $f(1, \ldots, 1) = 1$, т.е. $f \in T_1$.

**Вывод**.
Любая функция из $T_0 \cap S$ автоматически принадлежит $T_1$. Следовательно:
$$T_0 \cap S \subseteq T_1 \quad \Rightarrow \quad (T_0 \setminus T_1) \cap S = \varnothing$$
#### Ответ
$$\boxed{R = (T_0 \setminus T_1) \cap S = \varnothing, \quad |R| = 0}$$

- $f_1(1,1) = 1$ → $f_1 \in T_1$
- $f_2(1,1,1) = 0$ → $f_2 \notin T_1$
- $f_3(1,1,1) = 1$ → $f_3 \in T_1$

**$S$ (самодвойственность): сравниваем $f(\sigma)$ и $\neg f(\bar{\sigma})$ для противоположных наборов.**
$f_1 = b$:
- $\neg f_1(1,1) = 0 = f_1(0,0)$ 
- $\neg f_1(1,0) = 1 = f_1(0,1)$ 
→ $f_1 \in S$

$f_2 = (1110\;1000)$:
- $(000) \leftrightarrow (111)$: $\neg f_2(1,1,1) = 1 = f_2(0,0,0)$ ✓
- $(001) \leftrightarrow (110)$: $\neg f_2(1,1,0) = 1 = f_2(0,0,1)$ ✓
- $(010) \leftrightarrow (101)$: $\neg f_2(1,0,1) = 1 = f_2(0,1,0)$ ✓
- $(011) \leftrightarrow (100)$: $\neg f_2(1,0,0) = 0 = f_2(0,1,1)$ ✓
→ $f_2 \in S$

$f_3 = a \oplus b \oplus c$:
- $(000) \leftrightarrow (111)$: $\neg f_3(1,1,1) = 0 = f_3(0,0,0)$ ✓
- $(001) \leftrightarrow (110)$: $\neg f_3(1,1,0) = 1 = f_3(0,0,1)$ ✓
- $(010) \leftrightarrow (101)$: $\neg f_3(1,0,1) = 1 = f_3(0,1,0)$ ✓
- $(011) \leftrightarrow (100)$: $\neg f_3(1,0,0) = 0 = f_3(0,1,1)$ ✓
→ $f_3 \in S$

**Все три функции принадлежат классу $S$** - ни одна не выходит за его пределы.
Дальнейшая проверка классов $M$ и $L$ уже не нужна, но для полноты таблицы:

**$M$ (монотонность):**
$f_1 = b$ - монотонна → $f_1 \in M$
$f_2$: $(0,0,1) \leq (0,1,1)$, но $f_2(0,0,1) = 1 > 0 = f_2(0,1,1)$ → $f_2 \notin M$
$f_3$: $(0,0,1) \leq (0,1,1)$, но $f_3(0,0,1) = 1 > 0 = f_3(0,1,1)$ → $f_3 \notin M$

**$L$ (линейность):**
$f_1 = b$ - линейна → $f_1 \in L$
$f_3 = a \oplus b \oplus c$ - линейна → $f_3 \in L$
$f_2$: находим полином Жегалкина подстановкой:
- $c_0 = 1$, $c_1 = 0$, $c_2 = 0$, $c_3 = 0$, $c_4 = 1$, $c_5 = 1$, $c_6 = 1$, $c_7 = 0$
