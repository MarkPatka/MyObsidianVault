## Алгоритм Дейкстры 

1. Инициализировать $d[s]=0$, $d[v]=\infty$ для всех остальных вершин.
2. Выбрать непосещённую вершину $u$ с минимальным $d[u]$.
3. Для каждого исходящего ребра $(u \to v)$: если $d[u] + w(u,v) < d[v]$, обновить $d[v]$ и запомнить предка $\text{prev}[v] = u$.
4. Пометить $u$ как посещённую.
5. Повторять шаги 2–4 пока не посетим $X_8$ (или не исчерпаем вершины).
6. Восстановить путь по массиву $\text{prev}$.

## Решение

$$d = [0,\ \infty,\ \infty,\ \infty,\ \infty,\ \infty,\ \infty,\ \infty], \quad \text{посещено: } \varnothing$$

1) Минимум среди непосещённых: $X_1\ (d=0)$. Помечаем $X_1$ посещённой.

Обновляем соседей $X_1$:

| Дуга          | Расчёт                 | Результат                            |
| ------------- | ---------------------- | ------------------------------------ |
| $X_1 \to X_2$ | $0 + 67 = 67 < \infty$ | $d[X_2] = 67,\ \text{prev}[X_2]=X_1$ |
| $X_1 \to X_6$ | $0 + 42 = 42 < \infty$ | $d[X_6] = 42,\ \text{prev}[X_6]=X_1$ |
| $X_1 \to X_7$ | $0 + 77 = 77 < \infty$ | $d[X_7] = 77,\ \text{prev}[X_7]=X_1$ |
$$d = [0^\checkmark,\ 67,\ \infty,\ \infty,\ \infty,\ 42,\ 77,\ \infty]$$
---

2) Минимум среди непосещённых: $X_6\ (d=42)$. Помечаем $X_6$ посещённой.

Обновляем соседей $X_6$:

| Дуга          | Расчёт                  | Результат                            |
| ------------- | ----------------------- | ------------------------------------ |
| $X_6 \to X_7$ | $42 + 74 = 116 > 77$    | без изменений                        |
| $X_6 \to X_8$ | $42 + 52 = 94 < \infty$ | $d[X_8] = 94,\ \text{prev}[X_8]=X_6$ |

$$d = [0^\checkmark,\ 67,\ \infty,\ \infty,\ \infty,\ 42^\checkmark,\ 77,\ 94]$$

---

3) Минимум среди непосещённых: $X_2\ (d=67)$. Помечаем $X_2$ посещённой.

Обновляем соседей $X_2$:

|Дуга|Расчёт|Результат|
|---|---|---|
|$X_2 \to X_1$|$X_1$ уже посещена|—|

|$X_2 \to X_7$|$67 + 19 = 86 > 77$|без изменений|

$$d = [0^\checkmark,\ 67^\checkmark,\ 128,\ \infty,\ \infty,\ 42^\checkmark,\ 77,\ 94]$$

---

5) Минимум среди непосещённых: $X_8\ (d=94)$ - это целевая вершина.
