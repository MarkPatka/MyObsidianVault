Рекурсивный спуск — это способ **разобрать текст по правилам грамматики**, где каждое правило — отдельная функция, которая может вызывать другие функции (в том числе себя).

«Спуск» — потому что мы идём от общих правил к частным (сверху вниз).

---

## Простой пример — подсчёт суммы чисел через запятую

Задача: разобрать строку `"3, 5, 2, 8"` и посчитать сумму.

Грамматика:

```
список → число (',' число)*
```

```csharp
string[] nums = "3, 5, 2, 8".Split(',');
int sum = 0;
foreach (var n in nums)
    sum += int.Parse(n.Trim());
```

Это совсем просто, потому что одно правило. Теперь усложним.

#### Пример с двумя уровнями — вычисление выражения

Задача: вычислить `2 + 3 * 4`. Правильный ответ — 14, а не 20.
```csharp
// токены: ["2", "+", "3", "*", "4"]
static string[] tokens;
static int pos;

static int Expr()        // + и - : низший приоритет
{
    int left = Term();
    while (pos < tokens.Length && tokens[pos] == "+")
    {
        pos++;
        int right = Term();
        left = left + right;
    }
    return left;
}

static int Term()        // * и / : высший приоритет
{
    int left = Factor();
    while (pos < tokens.Length && tokens[pos] == "*")
    {
        pos++;
        int right = Factor();
        left = left * right;
    }
    return left;
}

static int Factor()      // просто число
{
    return int.Parse(tokens[pos++]);
}
```

**Трассировка `2 + 3 * 4`:**

```
Expr()
├── Term()          ← разбирает "2"
│   └── Factor()   → возвращает 2, pos теперь на "+"
│   └── видит "+", это не "*" — выходим
│   └── возвращает 2
├── видит "+", pos++, теперь на "3"
├── Term()          ← разбирает "3 * 4"
│   └── Factor()   → возвращает 3, pos теперь на "*"
│   └── видит "*", pos++, теперь на "4"
│   └── Factor()   → возвращает 4
│   └── left = 3 * 4 = 12
│   └── возвращает 12
└── left = 2 + 12 = 14 ✓
```

Приоритет соблюдается автоматически: `Expr` не может «перепрыгнуть» через `Term` — он всегда ждёт, пока `Term` не соберёт всё своё.

## Пример задачи
### Условие
```
# Задание: Расставить скобки

На вход функции подается подается строка, являющаяся арифметическим выражением.

Необходимо произвести разбор строки и расставить в ней скобки (круглые), таким образом, чтобы получилась полная скобочная конструкция. 

Строка может содержать:  
- четыре арифметических операции `+` `-` `*` `/`  
- числа (целые и вещественные, разделитель запятая)  
- скобки

При расстановке скобок соблюдать стандартный приоритет операций.

Функция формирует список с отдельными лексемами и возвращает его в main.  
main выводит элементы списка в консоль.  
Разделители лексем - пробелы.

Пример:

Входная строка: 6 * ( 5 + 2 ) - 12,6

Результат: ( ( 6 * ( 5 + 2 ) ) - 12,6 )
```
### Решение
```csharp
class Program
{
    static List<string> tokens;
    static int pos;

    static void Main()
    {
        string input = "6 * ( 5 / 2 ) - 12,6";
        List<string> result = Parenthesize(input);
        Console.WriteLine(string.Join(" ", result));
    }

    static List<string> Parenthesize(string input)
    {
        tokens = [.. input.Split(' ', StringSplitOptions.RemoveEmptyEntries)];
        pos = 0;
        return ParseExpression();
    }

    // Низший приоритет: + и −
    static List<string> ParseExpression()
    {
        var left = ParseTerm();

        while (pos < tokens.Count && (tokens[pos] == "+" || tokens[pos] == "-"))
        {
            string op = tokens[pos++];
            var right = ParseTerm();
            left = Wrap(left, op, right);
        }

        return left;
    }

    // Высший приоритет: * и /
    static List<string> ParseTerm()
    {
        var left = ParseFactor();

        while (pos < tokens.Count && (tokens[pos] == "*" || tokens[pos] == "/"))
        {
            string op = tokens[pos++];
            var right = ParseFactor();
            left = Wrap(left, op, right);
        }

        return left;
    }

    // число или явно скобочное подвыражение
    static List<string> ParseFactor()
    {
        if (pos < tokens.Count && tokens[pos] == "(")
        {
            pos++;                          // пропускаем '('
            var inner = ParseExpression();
            pos++;                          // пропускаем ')'
                                            
            return inner;
        }

        return [tokens[pos++]];
    }

    static List<string> Wrap(List<string> left, string op, List<string> right)
    {
        var result = new List<string> { "(" };
        result.AddRange(left);
        result.Add(op);
        result.AddRange(right);
        result.Add(")");
        return result;
    }
}
```
### Пояснения к решению
#### Откуда вообще берётся структура?

Арифметика имеет **правила приоритета**: `*` и `/` выполняются раньше `+` и `-`. Чтобы это выразить в коде, мы описываем три «уровня», каждый из которых отвечает за свои операции:

```
ParseExpr   — отвечает за + и −  (низший приоритет)
ParseTerm   — отвечает за * и /  (высший приоритет)
ParseFactor — отвечает за атомы: числа и скобочные выражения
```

Они **вызывают друг друга по цепочке сверху вниз**, и именно эта цепочка обеспечивает правильный приоритет.

---
#### Глобальные переменные

```csharp
static List<string> tokens; // список токенов: ["6", "*", "(", "5", "+", "2", ")", "-", "12,6"]
static int pos;             // «курсор» — какой токен мы сейчас читаем
```

`pos` — это указатель, который всегда движется только вперёд. Каждый раз, когда мы «прочитали» токен — делаем `pos++`. Это как чтение книги: прочитал слово — перешёл к следующему.

---
#### Метод `Parenthesize` — точка входа
```csharp
static List<string> Parenthesize(string input)
{
    tokens = new List<string>(
        input.Split(' ', StringSplitOptions.RemoveEmptyEntries)
    );
    pos = 0;
    return ParseExpr(); // запускаем разбор с низшего приоритета
}
```

Просто разбивает строку на токены по пробелу и запускает разбор. Возвращает готовый список с расставленными скобками.

---

#### `ParseExpr` — обработка `+` и `−`

```csharp
static List<string> ParseExpr()
{
    var left = ParseTerm(); // сначала разбираем ЛЕВУЮ часть через ParseTerm

    while (pos < tokens.Count && (tokens[pos] == "+" || tokens[pos] == "-"))
    {
        string op = tokens[pos++]; // запоминаем оператор и сдвигаем курсор
        var right = ParseTerm();  // разбираем ПРАВУЮ часть через ParseTerm
        left = Wrap(left, op, right); // оборачиваем: ( left op right )
    }

    return left;
}
```

**Ключевая мысль:** `ParseExpr` не занимается `*` и `/` — он делегирует это `ParseTerm`. Поэтому когда `ParseExpr` видит `6 * 2 + 3`, он сначала просит `ParseTerm` собрать `6 * 2` целиком — и только потом добавляет `+ 3`. Это и есть приоритет.

Цикл `while` нужен для **цепочки операций**: `1 + 2 + 3 + 4`. Каждую итерацию мы дополняем `left`:

```
шаг 1: left = [1]
шаг 2: left = ( 1 + 2 )
шаг 3: left = ( ( 1 + 2 ) + 3 )
шаг 4: left = ( ( ( 1 + 2 ) + 3 ) + 4 )
```

---
#### `ParseTerm` — обработка `*` и `/`

```csharp
static List<string> ParseTerm()
{
    var left = ParseFactor(); // идём ещё ниже — к атомам

    while (pos < tokens.Count && (tokens[pos] == "*" || tokens[pos] == "/"))
    {
        string op = tokens[pos++];
        var right = ParseFactor();
        left = Wrap(left, op, right);
    }

    return left;
}
```

Структура **идентична** `ParseExpr`, но работает с `*` и `/`, и делегирует вниз уже `ParseFactor`.

---
#### `ParseFactor` — атомы

```csharp
static List<string> ParseFactor()
{
    if (pos < tokens.Count && tokens[pos] == "(")
    {
        pos++; // пропускаем открывающую скобку
        var inner = ParseExpr(); // внутри скобок — снова полное выражение!
        pos++; // пропускаем закрывающую скобку
        return inner; // inner уже обёрнут — не добавляем лишних скобок
    }

    // если не скобка — это число, просто берём его
    return new List<string> { tokens[pos++] };
}
```

Здесь два случая:

- **Встретили `(`** — значит внутри скобок новое подвыражение. Пропускаем `(`, рекурсивно разбираем содержимое через `ParseExpr`, пропускаем `)`.
- **Встретили число** — просто берём его и сдвигаем курсор.

---
#### `Wrap` — сборка скобок

```csharp
static List<string> Wrap(List<string> left, string op, List<string> right)
{
    var result = new List<string> { "(" };
    result.AddRange(left);   // добавляем левую часть
    result.Add(op);          // добавляем оператор
    result.AddRange(right);  // добавляем правую часть
    result.Add(")");
    return result;
}
```

Просто клеит три части в одну: `( [left] op [right] )`. Это и есть то место, где скобки реально добавляются.
